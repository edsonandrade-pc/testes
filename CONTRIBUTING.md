# Contribuindo

1. Crie uma branch: `feat/nome-curto`.
2. Faça mudanças pequenas e focadas.
3. Rode checks locais antes do commit.
4. Abra PR com:
   - contexto
   - como testar
   - impacto

## Convenções

- Commits semânticos (`feat`, `fix`, `docs`, `refactor`, `test`, `chore`).
- README atualizado quando alterar comportamento de execução.
