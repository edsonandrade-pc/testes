# Roadmap Prático (12 semanas)

## Bloco 1 — Fundamentos de produção
- Logs estruturados.
- Tratamento de erros padronizado.
- Organização de pastas por domínio.

## Bloco 2 — Qualidade
- Testes unitários + integração.
- Lint + formatter automatizados.
- Checklist de code review.

## Bloco 3 — Entrega
- Docker básico por projeto.
- CI simples (test + build).
- Deploy em ambiente gratuito.

## Bloco 4 — Diferencial
- Projeto autoral com problema real.
- Métricas (tempo de resposta, erros).
- Documentação para onboarding rápido.
